# ai-coursework-group13
My primary responsibility in this project was the implementation of Task 2: Temporal Drift Analysis via Dimensionality Reduction. I designed and executed the PCA (Principal Component Analysis) pipeline to visualize the trajectory of AI, ML and NLP abstracts over time (1999-2021).
My specific contributions included:
•	Developing the script for high-dimensional feature extraction using both TF-IDF (lexical) and SBERT (semantic) representations.
•	Implementing the PCA reduction logic and standardizing data to ensure variance was captured accurately.
•	Creating a temporal visualization script that calculates yearly centroids to map the field's "trajectory."
•	Coordinating with the "Preprocessing" lead to ensure data cleaning was consistent across the group's pipeline.
•	Report writing assistance.
